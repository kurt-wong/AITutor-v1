推荐路线：先 A+D → 再 B

第 0.5 天 (A+D 融合) — 在现有 main.tsx 的 ConfigProvider 中配置 seed token（colorPrimary: '#16a34a'） + algorithm + component token（Menu/Card/Table/Button）。同时覆盖品牌色、深色侧栏、圆角、字体、组件微调五大维度。零风险，可随时回滚。

第 1-5 天 (方案 B) — 安装 Tailwind CSS v4，逐步为每个页面的布局/间距加上 Tailwind 类。保留 Ant Design 处理 Table/Tree/Form/Upload。AskPage 和 StatisticsPage 优先迁移。

A+D 融合了方案 A 的品牌色能力和方案 D 的算法切换能力，0.5 天达到最高性价比的基线效果。之后渐进推进方案 B 提升到品质天花板。
